API Documentation
About The Text Only Holy Bible Recovery Version API ^
The Text Only Holy Bible Recovery Version API is a simple HTTP URL API that can be used to access verses from the Holy Bible Recovery Version for integration into other software or plugins.

How to use this API ^
This API can be accessed using a simple HTTP GET request with Basic Authentication (See IETF and MDN for more information). The general structure of the request string is as follows:

curl https://baseurl/txo.php? -u appid:token -H 'Accept: application/json' -d String=verses -d Lang=eng -d In=osis

https://appid:token@baseurl/txo.php?String=verses&In=osis&Lang=spa&Out=json
where:

appid
Refers to a user generated app identifier created at api.lsm.org.
token
Refers to the token assigned to an app at api.lsm.org.
baseurl
Refers to the location where the API resides such as 'https://api.lsm.org/recver'.
String
Is a variable containing the list of verses to be requested provided either in default input mode as 'Prov. 29:18; Acts 26:19; Eph. 4:4-6; Rev. 21:2, 9-10'
or in OSIS input mode as Proverbs.29.18,Acts.26.19,Ephesians.4.4-Ephesians.4.6,Revelation.21.2,Revelation.21.9-Revelation.21.10. Note that in OSIS input mode the requested verses string is not encapsulated in single quotes.
Out
Optional: Is a variable that specifies JSON as the response output (default output is XML). Note that in the curl command the mode can be specified as an Accept header variable.
In
Optional: Is a variable that specifies OSIS as the input format for verses.
Lang
Optional: Is a variable that specifies the language for the verse references (Default language is English, and values are: spa for Spanish, and eng for English.)
Default Input Format ^
A valid input string in the default input mode consists of no more than six kinds of characters, these are: alphabets including the period punctuation and the hyphen, numbers, commas, colons, semicolons, and spaces. Using any other kind of character in an input string will result in an error and no output.

While there are various verse referencing styles, only the style defined below will work with this API.

The use of Alphabets and Numbers ^
A general rule to observe when constructing a valid input string is that whereas book names may include alphabets and numbers, book chapters and verse numbers can include only Arabic numerals. Hence, while the reference:

Hebrews 1:4 is valid,
Hebrews I.IV is not valid,
Hebrews I:IV is not valid, and
Hebrews I,IV is not valid.
The use of Periods, Commas, and Semicolons ^
The API also understands periods, commas, and semicolons in a specific way.

The period is allowed only for book name abbreviations. For instance:

Matt. 28:19 is valid, but
Matt. 28.19 is not valid
The semicolon is used either for the separation of two or more full references or for references within the same book but in different chapters. For instance:

Prov. 29:18; Acts 26:19 is valid, and
Acts 9:22; 26:19 is valid
The comma is allowed only for additional verse citations within the same book and chapter. Some examples are:

John 1:1, 14
Heb. 1:2, 5-6, 8
Note: Be careful not to switch semicolons for commas and vice versa.

As you may have observed in the examples above, the colon is used only to separate verse numbers and chapter numbers.

Based on the overview above, a simple input string will consist of only alphabets, numbers, and colons. Examples include:

Acts 13:13
Jude 9
Eph. 4:6-4

and a complex input string may consist of all allowed character sets. For instance:

Prov. 29:18; Acts 26:19
Prov. 29:18; Acts 26:19; John 1:12-13, 16
A final note regarding single chapter books is that they are to be referenced as though they contained only verses. For instance:

Jude 9 is valid, but
Jude 1:9 is not valid.

Output Format ^
When the API is provided an input, it will default to returning a well formed XML file titled verses.xml. However, it can return a JSON file titled verses.json when the "Out" parameter is set to json (&Out=json). The default verses.xml file is structured as follows:

<?xml version="1.0" encoding="utf-8" ?>
<request>
    <inputstring></inputstring>
    <detected></detected>
    <verses>
        <verse>
            <ref>reference</ref>
            <text>verse text</text>
            <urlpfx>URL postfix</urlpfx>
        </verse>
        <verse>
            <ref>reference</ref>
            <text>verse text</text>
            <urlpfx>URL postfix</urlpfx>
        </verse>
    </verses>
    <message>errors</message>
    <copyright>copyright string</copyright>
</request>
    
where:

<request></request>
Is the top-level container for an entire request.
<inputstring></inputstring>
Contains the actual input, the list of verses sent to the API.
<detected></detected>
Contains what the API recognizes after error correction and format fixes.
<verses></verses>
Is a container for all verses requested.
<verse></verse>
Is a container for a single verse in the list of requested verses.
<ref></ref>
Contains a properly formated reference for a requested verse.
<text></text>
Contains the text from a requested verse.
<urlpfx></urlpfx>
Contains the URL postfix to generate Recover Version website and app link (i.e. https://text.recoveryversion.bible/<urlpfx>).
<message></message>
Contains information on any errors encountered while processing a request.
<copyright></copyright>
Contains the copyright string that should be displayed along with the verses in the software accessing this API.
The verses.json file is structured as follows:

{
"inputstring": "",
"detected": "",
"verses": [
           {"ref": "reference", "text": "verse text", "urlpfx": "URL postfix"},
           {"ref": "reference", "text": "verse text", "urlpfx": "URL postfix"}
       ],
"message": "errors",
"copyright": "copyright string"
}
          
where:

"inputstring"
Contains the actual input, the list of verses sent to the API.
"detected"
Contains what the API recognizes after error correction and format fixes.
"verses"
Is a container for all verses requested.
"ref"
Contains a properly formated reference for a requested verse.
"text"
Contains the text from a requested verse.
"urlpfx"
Contains the URL postfix to generate Recover Version website and app link (i.e. https://text.recoveryversion.bible/<urlpfx>).
"message"
Contains information on any errors encountered while processing a request.
"copyright"
Contains the copyright string that should be displayed along with the verses in the software accessing this API.
